# Политика безопасности

## Поддерживаемые версии
Поддерживается только последняя версия из ветки `main`.

## Известные ограничения
- Сообщения между клиентом и сервером передаются **без шифрования**. Не отправляйте пароли и личные данные.
- Сервер не проверяет личность участников: любой, кто знает адрес, может войти под любым именем.
- Клиент скачивает обновления из этого репозитория через `git pull`. Запускайте только клиент из репозитория, который вы сами клонировали.

## Сообщить об уязвимости
Пишите в личные сообщения автору или откройте приватный запрос через раздел **Security → Report a vulnerability** на GitHub. Публично уязвимости не описывайте до исправления.

Ответ обычно приходит в течение недели.
