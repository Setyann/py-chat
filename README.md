# Чат друзей — клиент

Десктопный клиент чата на Python и PySide6. Подключается к серверу в локальной сети или через Radmin VPN.

## Требования
- Windows 10/11 (на других ОС работает, но не проверялось)
- Python 3.10+
- Git
- PySide6: `pip install PySide6`

## Установка

```
git clone https://github.com/Setyann/py-chat.git
cd py-chat-client
python client_qt.py
```

## Использование
1. Введите имя и нажмите «Войти».
2. Пишите сообщения в нижнее поле, Enter отправляет.
3. Кнопка 😀 открывает панель эмодзи.
4. История последних сообщений загружается при входе.

## Обновления
При запуске клиент проверяет `version.txt` в репозитории. Если есть новая версия, появится запрос. После подтверждения обновление ставится через `git pull` и приложение перезапускается.

## Структура
- `client_qt.py` — клиент
- `version.txt` — номер последней версии

## Сервер
Сервер в этот репозиторий не входит и запускается отдельно.
